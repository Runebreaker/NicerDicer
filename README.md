# NicerDicer
A weaverdice discord bot.

## Features - Basic
- [x] Dice Rolls (Format: /roll 3d6+4)
- [x] Wound Rolls (See: https://docs.google.com/document/d/1qyyXT2FGvWfe8SxF0oLEXbNnuXGAolSXYwHNjErBCbA/edit?usp=sharing, under "Wound Effects, Format: /wound 1m1l poison 1m bash)
- [x] Augment/Perk Rolls (Format: /augmen, /perk, see: https://docs.google.com/spreadsheets/d/1UK1o9Vb15kYFVkfa9qEh9BBNCB7R6IBIUMD1YSHOHjE/edit?gid=403439930#gid=403439930)
- [x] Tag System
- [x] Alignment and Reputation!
- [x] Rolling for Mooks and Mercs!
- [x] The ability to throw your dice away! 😌
      
## Features - Advanced
- [x] Combat! Automatic initiative, turn timers and reminders!
- [x] Draw Cards
- [x] Factions and Territories!
